# Documentação do KALUM_app

Esta pasta reúne a especificação funcional e técnica do KALUM_app.

## Escopo aprovado

Aplicação web de comunicação interna, exclusiva para funcionários da Kalunga, com conversas privadas individuais. A primeira versão será desktop-first, com prioridade para Google Chrome.

## Tecnologias definidas

- **Vercel:** hospedagem e implantação.
- **Supabase:** plataforma de backend e dados.
- **Demais tecnologias e arquitetura:** pendentes de definição pela equipe técnica.

- Requisitos aprovados devem ser identificados e rastreáveis.
